# GitHub Release Notes — v1.0.0

## ComfyUI Load Image Media Browser 1.0.0

First GitHub-ready release of **ComfyUI Load Image Media Browser**.

### Highlights

- media browser for **Load Image** and **Load Video**
- images and videos visible in both browser contexts
- node-safe media selection per node type
- folder memory and current-folder navigation
- image/video visibility toggles
- sorting by date and name
- delete support
- automatic preview resizing
- aspect-ratio presets for common media formats

### Install

Copy the repository folder into:

`ComfyUI/custom_nodes/ComfyUI-Load-Image-Media-Browser`

Restart ComfyUI and hard refresh the browser UI.
